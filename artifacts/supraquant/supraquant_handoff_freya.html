01 Greeting

Dear Freya,

This page is a concise technical handoff of an experimental closed spline construction we have been calling SupraQuant. It was developed with your 2022 talk The Continuity of Splines (and your later public experiments with higher-degree interpolating C² curves) as the primary design brief.

The goal was to explore whether a non-polynomial, sine-based basis with pre-filtering can simultaneously deliver interpolation, local control, and continuity beyond the classic cubic regime while remaining practical for interactive use.

Nothing here claims to be finished or definitive. It is offered as a working prototype and diagnostic sandbox in the hope that some of the design choices (or the failure modes) are useful to you.

02 The gap you described

Your video and subsequent posts repeatedly surface a practical tension that is still not fully resolved in everyday tools:

Cubic B-spline

Reliable C² + local control, but approximating — does not pass through the control points.

Catmull-Rom

Interpolates and stays local, but stops at C¹. Acceleration / curvature usually discontinuous.

Natural cubic

Interpolates and reaches C², at the cost of global coupling — move one point, the whole curve shifts.

Higher-degree polys

Can force more continuity, yet “fairness” (smooth, low-energy, non-stiff shapes) becomes difficult.

SupraQuant is an attempt to sit in the remaining region: interpolating, locally supported, closed, and intentionally aimed at G⁴ / continuous-jerk behaviour, using a sine-based analogue of the Cox–de Boor recursion plus a collocation pre-filter.

03 What SupraQuant is

At its core it is a periodic cubic-degree spline whose basis functions replace the usual linear ratios with normalised sines of angular differences. A scale factor keeps the arguments away from integer multiples of π. Strict 2π-periodicity is enforced by normalising the evaluation angle at every level of the recursion.

Because the raw basis is approximating, a dense collocation matrix is built at the knot-aligned sample locations and inverted so that virtual control points make the curve pass exactly through a set of user-specified target points. Partition-of-unity is restored by renormalising the active basis weights after evaluation.

Basis

evaluateSupraQuantBasis — sine-corrected Cox–de Boor with θ forced into [0, 2π) on every recursive entry.

Weights

getSupraQuantWeights — four active bases, periodic index wrap, renormalise so ∑w = 1.

Pre-filter

solvePreFilteringMatrix — collocation B·Cvirtual = Dtarget (Gaussian elim. + partial pivoting).

Diagnostics

Live curvature combs, acceleration magnitude, and jerk / jolt plots over the full [0, 2π] domain.

05 Core basis (excerpt)

Sine-based Cox–de Boor analogue with strict periodicity at every recursion level.

export function evaluateSupraQuantBasis(i, p, theta, knots, scaleFactor) {
  const normTheta = ((theta % (2 * Math.PI)) + 2 * Math.PI) % (2 * Math.PI);
  if (p === 0) {
    return (normTheta >= knots[i] && normTheta < knots[i + 1]) ? 1.0 : 0.0;
  }
  const sinDenom1 = Math.sin((knots[i + p] - knots[i]) * scaleFactor);
  const sinDenom2 = Math.sin((knots[i + p + 1] - knots[i + 1]) * scaleFactor);
  let term1 = 0.0, term2 = 0.0;
  if (Math.abs(sinDenom1) > 1e-6) {
    term1 = (Math.sin((normTheta - knots[i]) * scaleFactor) / sinDenom1)
          * evaluateSupraQuantBasis(i, p - 1, normTheta, knots, scaleFactor);
  }
  if (Math.abs(sinDenom2) > 1e-6) {
    term2 = (Math.sin((knots[i + p + 1] - normTheta) * scaleFactor) / sinDenom2)
          * evaluateSupraQuantBasis(i + 1, p - 1, normTheta, knots, scaleFactor);
  }
  return term1 + term2;
}

06 Known limitations

Fairness is empirical

Higher continuity ≠ automatic low-energy shapes. Aggressive edits can still reveal stiffness; the scale factor helps but is not a complete answer.

Numerical derivatives

Finite differences are used for curvature / jerk plots. Analytic derivatives of the sine basis would improve accuracy and speed.

Degree / support

A pure cubic construction has limited degrees of freedom once interpolation + high continuity are demanded. Higher-degree sine bases remain open.

Global pre-filter

Collocation is O(n³). Fine for interactive dozens of points; hundreds will need incremental / sparse techniques.

07 Why it may interest you

You have publicly explored the same design space — most recently an interpolating C² quintic that keeps local control. SupraQuant is a different route to a related destination: a non-polynomial periodic basis + collocation, rather than a higher-degree polynomial with carefully chosen constraints.

The live curvature-comb and jerk diagnostics are intentionally in the visual vocabulary of your 2022 talk, so the continuity behaviour can be inspected in the same terms you already use.

If the construction is ultimately a dead end, the failure modes themselves may still be informative. If it survives contact with a sharper eye, the sine-basis + pre-filter pattern might be a useful additional tool alongside the polynomial family. — from the original handoff note
